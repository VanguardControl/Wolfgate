# FeatureBans

Bans from Wolfgate features, made like job bans. Each `wfFeatureBan` prototype is a feature an admin can ban a
player from: it shows in the ban panel's Features group, and `roleban <player> <feature id> ...` works too. The ban
is stored as a role ban on `Feature:<id>`, so the ban list, notes and pardons treat it like any other role ban.

`FeatureBanSystem.IsBanned` answers for a connected player, and `FeatureBannedEvent` is raised when a ban lands on
one, so the feature can take back what they have of it at once. The client reads its own bans from
`JobRequirementsManager.IsFeatureBanned` to grey out what it can't use.

Features: `WFAppearanceStudio` (the Appearance Studio and custom markings).
