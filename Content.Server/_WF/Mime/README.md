# Mime

The Mime trait's abilities, ported from Wayfarer (`a7f18f6fa85`). A mime holds a vow of silence and gets two
action buttons: an invisible box that keeps what is stored in it between summons, and a finger gun that does no
damage but the target will see the screen getting redder.

Differences from the source: the vow can't be broken (`VowOfSilenceUnbreakable`) and doesn't stop writing, the mime
vow implanter is gone from the Contractor loadout, the finger gun shot has no tracer (Monolith's base bullet adds one).

Entry points: `MimeSummonSystem` (both summons and the box), `FingerGunSystem` and the client
`FingerGunOverlaySystem`.
