# GodPanel

The gamemaster's overwatch window: a sector map, a roster of every player and ship, up to six camera feeds, a
timeline of what just happened and a context bar that acts on whatever is selected. Opened with `godpanel` or the
God Panel button in the Wolfgate admin tab (Admin flag). Every action goes through the system that already owns it
(Second Chance, Offer to Ghosts, grid power, ship PA, encounters, the Reaver campaign, war level, internet sounds,
hails) and is checked against that tool's flag on the server, so the panel adds no new powers, only one place to
use them from.

Entry points: `WFGodPanelSystem` (server: subscriptions, the state sent every second, feeds, actions and the event
log, split into partials), the client `WFGodPanelSystem` (state, log and feeds) and `WFGodPanelWindow` (the window
and its panes). `Docs/_WF/GodPanel/design.md` is the design.
