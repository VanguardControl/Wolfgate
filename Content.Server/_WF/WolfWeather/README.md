# WolfWeather

Rain, snow, storms and fog drawn by one shader, stopped by roofs, with wind that pushes loose items,
weather-tinted map light and looping sounds listed on each weather. Admins drive it with `wolfweather` and
`wolfweather_schedule`. Storms flash and strike lightning that shocks whoever it hits.
A weather can copy another with `parent` and change single layers with `layerOverrides`, as the blood weathers do.

Entry points: `SharedWolfWeatherSystem.SetWeather`, `WeatherScheduleSystem.SetSchedule`, the `wolfWeather` and
`weatherSchedule` prototypes and the `WeatherSchedule` component.
