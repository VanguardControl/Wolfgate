# CorpseRadar

When a player's character dies, its body shows on every ship's radar (mass scanner) as a small red diamond, like a
suit sensor that only reports a flatline. The marker is drawn on ships and in open space, within the usual 2048 m blip
range of the viewing console, and stays while the body is dead even after the player ghosts. Reviving the body removes
it; a gibbed or deleted body takes it along. NPC bodies get no marker.

Entry point: `WFCorpseRadarSystem`, which adds Mono's `RadarBlipComponent` to the body on death and marks it with
`WFCorpseRadarComponent` so revival removes only the blip it added.
