# PlanetPois

Points of interest on a bounded world, rolled afresh each round. Before a world's ground preloads (the Planets
`WFPlanetPreloadStartingEvent`), `WFPlanetPoiSystem` draws sites from the surface's `wfPlanetPoiTable` (`pois` on the
`wfPlanetSurface`): random origins inside the circle, clear of the edge, the centre, each other and anything already
pinned such as a cavern mouth. Each site is a procedural dungeon (`Resources/Prototypes/_WF/PlanetPois/dungeons.yml`:
Frontier's planet-base interiors with mobs and loot layers on top) generated straight onto the ground grid and pinned,
so the biome never lays terrain over it; the preload waits for every dungeon before it loads a chunk. Each site gets a
marker on the orbit layer (`WFPoiSignal`, a warp point and radar label) called "Unknown signal" until someone on the
ground comes within the table's `revealRange`, when it takes the site's name and the finder is told. What was placed is
on the ground's `WFPlanetPoiComponent`.
