# CorticalBorer

Fixes for Mono's cortical borers. A borer taken out of a host it is controlling ends its control, so the host's player
gets their body back and the borer's player goes back into the borer. Mono's eject clears the borer's host without
ending control, after which neither the control timer nor the End Control action can undo the mind swap. The borer
removal surgery ejected that way and left the borer's player in the body and the patient's in the fish fillet that
holds a controlled host's mind.

Entry points: `EndControlOnEjectSystem`, which calls Mono's `CorticalBorerSystem.EndControl` when a borer comes out of
a container. That happens inside `SharedCorticalBorerSystem.TryEjectBorer`, before it clears the host, so every eject
is covered: the removal surgery, which Mono leaves open, and the paths that already end control themselves, where the
second call does nothing. `EndControlOnEjectTest` covers the surgery, a direct eject and a removal with no control
active.
