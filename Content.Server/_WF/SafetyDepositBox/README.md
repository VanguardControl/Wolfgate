# SafetyDepositBox

Safety deposit boxes, ported from Wayfarer. A console sells small, medium and large boxes paid from the player's bank
accounts, keeps a deposited box between rounds and hands it back on withdrawal. A lost box can be reclaimed: its
record is dropped and a new empty box spawned. Items that have been in a box say so on examine.

Entry points: `SafetyDepositBoxSystem` (purchase, deposit, withdraw, reclaim), `SafetyDepositConsoleComponent` and
`SafetyDepositBoxComponent`, `SafetyDepositStoredSystem` (examine text), and `SafetyDepositConsoleWindow`.
