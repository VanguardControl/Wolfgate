# ProfileSaves

Stops overlapping saves of one player's characters from colliding in the database.

A character save deletes the character's trait rows and inserts them again. Two overlapping saves can both do that, and
the second then breaks `IX_trait_profile_id_trait_name` and is lost. Saves come from the character editor and from
`BankSystem`, so a player can easily cause two at once. `WFUserWriteQueue` runs each player's saves, slot deletions and
character selections one at a time in the order they were asked for, from `ServerDbManager`. Other players' saves aren't held up.
