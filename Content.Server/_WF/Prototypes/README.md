# Prototypes

Keeps saved data loading after a Wolfgate prototype is renamed. `WFLegacyPrototypeIds` maps old ids to current ones,
one table per kind (consent toggles, genital shapes, HUD themes, loadouts, ship alert codes, species), and resolves
profiles and character exports. `WFLegacyDbRows` rewrites a loaded profile or consent row, so the load that finds an
old id also saves the new one. Renamed entity ids go in `Resources/migration.yml` instead.

Renaming a saved id means adding the old one to its table; `WFLegacyPrototypeIdsTest` checks that every entry maps to
an existing prototype and that no old id still exists.
