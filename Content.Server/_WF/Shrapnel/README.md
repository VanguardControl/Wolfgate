# Shrapnel

Destroyed machines that burst into shrapnel instead of exploding. `ShrapnelBehavior` is a destructible threshold
behavior that flings a ring of projectiles outward, like a shrapnel grenade. Gyroscopes use it in place of the blast
Monolith#4783 gave them, so a gyroscope destroyed in combat wounds the crew around it without breaching the hull.

Entry points: `ShrapnelBehavior` (`!type:ShrapnelBehavior` in a `Destructible` threshold) and `ShrapnelSystem.Fling`.
The shrapnel starts just outside the entity's tile, so the machine frame left there doesn't catch it, and it keeps a
moving ship's velocity. `ShrapnelBehaviorTest` covers the gyroscope.
