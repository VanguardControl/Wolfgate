# Roles

Custom job titles. For roles that allow one (currently Contractor), players write their own title with the Custom Job
button on the job row in the profile editor. The title is cleaned and checked live against the role's rules, and at
spawn it goes on the character's ID card, mind and station records.

Entry points: `CustomJobTitlePrototype` (per role: maximum length, blocked titles and words; its id is the role
loadout id), `CustomJobTitleRules` (cleaning and checks shared by client and server), `CustomJobTitleWindow`, and
`CustomJobTitleSystem` (applies the title at spawn). `CustomJobTitleComponent` holds the title on the mind.
