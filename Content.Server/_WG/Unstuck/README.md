# Unstuck

An **Unstick me** button in the game menu (Escape) for players wedged inside a wall, door, window or other solid
structure. The server moves them to the nearest clear floor within three tiles, preferring floor with breathable air,
and stops any pull. It only acts when the body really overlaps a static structure it collides with, so it can't be used
to walk out of a locked room or a cell; anyone trapped another way is told to ahelp. Ghosts, bodies in a container and
buckled bodies are refused. Each player can use it once every 30 seconds, and every use goes to the admin log as a
`Teleport` entry.

Entry points: `WGUnstuckSystem.TryUnstuck` (server), the `UnstuckButton` in `EscapeMenu.xaml` and its handler in
`EscapeUIController`, which sends `WGUnstuckRequestEvent` through the client `WGUnstuckSystem`.
