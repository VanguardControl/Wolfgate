# TileMovement

SS13-style movement. A mob with `WFTileMovement` steps from tile centre to tile centre on a grid instead of
moving freely: holding a direction walks tile by tile (diagonals included), letting go finishes the current step,
walls block the step before it starts and a step stopped by anything else (a mob, a locked door) walks back.
Players pick it as the **Tile walker** quirk trait.

The logic is a partial of `SharedMoverController` (`ApplyTileMovement`), called from `HandleMobMovement` when the
mob is grounded and directly on a grid; it overrides the computed velocity, so speed modifiers, prediction and
footsteps work as normal. Weightless, off-grid or inside a container, movement is unchanged.
