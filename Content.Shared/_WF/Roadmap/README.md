# Roadmap

The roadmap window, ported from RMC-14 (MIT): what is in the game, what is coming and what is planned, in columns of
collapsible items with a coloured bar per state (red planned, blue in progress, yellow partial, green complete). It
opens once per launch on reaching the lobby, after the rules popup if one is up, and from the Roadmap link in the lobby
strip and the game menu. Discord and Patreon buttons show when the server sets `infolinks.discord` and
`infolinks.patreon`.

Entries are data: each `roadmapColumn` prototype in `Resources/Prototypes/_WF/Roadmap/roadmap.yml` holds a heading and
its items, and every string is in `roadmap.ftl`. Edit those two files to update the roadmap. Entry points:
`RoadmapUIController` (auto-open and toggle) and `RoadmapWindow`. `RoadmapTest` checks the strings and markup and that
the window builds.

Changes from RMC: entries moved from XAML into prototypes and Fluent, and the lobby link uses the Wolfgate strip style.
