# NpcCrew

Human-style NPC crew for ships: each NPC works a job (helm, radio, guard post) and drops it to fight when a hostile is
in view, then goes back to work. Place a pilot NPC on a ship and it takes the helm and flies its orders (hold, go to,
loiter, follow, dock); a radio officer narrates docking, jumps and attacks on Shortband and Broadband. Mappers place
crew with spawn markers; admins use `wf_crew` to spawn crew and give orders. Design only so far: `design.md` is the
brief, built on the HTN planner, upstream piloting and Mono's ship steering. Planned entry points: `WFCrewComponent`
and `WFCrewSystem` (core), `WFPilotDutySystem` (orders API), `WFRadioOperatorSystem`, `WFCrewAlertSystem`.
