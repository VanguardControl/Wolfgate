# MeridianStructures

Meridian Rift's wall, window, door and grille sprites (from its NovaSector and tgstation art) on copies of the
upstream structures. Each `WFMeridian<Id>` entity is the upstream `<Id>` with only its sprite changed, so
access, wires, construction and damage behave the same; deconstructing one gives upstream parts back.
Only the structures Meta Station uses have variants; the black hole event map in `BlackHoleEvent` places them.

Everything in the module's `Resources` folders is generated. To change it, edit the generator and run it
from the repository root against a Meridian Rift checkout, which also rewrites the event maps:

```
python Tools/_WF/MeridianStructures/port.py --source <Meridian-Rift checkout> --write
python Tools/_WF/Ci/modules.py --write
```

Without `--write` it only lists what it would convert; `--review <file>` writes a sheet of every replaced
state beside the upstream one. The generator's header says how SS13 junctions become corner states and
what is left upstream.

- Walls, full-tile windows and shuttle walls take their corner quadrants from SS13 bitmask junctions.
- Airlocks compose the frame with its fill or glass, with lights, panels and sparks in a per-family
  effects RSI. Head-of-staff doors use Nova's own sheets; maintenance hatches keep the maintenance look.
- Opening and closing animations keep the upstream length, so door timing doesn't change.
- Meridian Rift has no uranium windows; those are its plasma windows shifted to green. Plasma windoors
  use the secure windoor.
