# Encounters

The Random Encounters System (RES): NPC-crewed faction freighters that cross the sector as mass scanner contacts and
load as real grids when a player closes in, with warning and fire zones, a crew that fights boarders, a captain on the
radio, and a payout for the owner faction's players who escort it home. Pirates board or destroy it for the freight;
"freighter under attack" and distress-signal encounters reuse the same lifecycle. Design only so far: `design.md` is
the full design, with what already exists in Monolith to build on (ship steering, ship guns, radar blips, companies,
bank) and the open questions. Planned entry points: `EncounterSchedulerSystem` (the storyteller rule),
`EncounterSystem` (lifecycle), `WFEncounterPrototype`, and the `wf_encounter` admin command.
