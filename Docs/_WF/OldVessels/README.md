# OldVessels

The 117 ships that Monolith#4624 (the shipyard refactor, autoported as Wolfgate #51) deleted, restored for review.
No station shipyard sells them: each vessel is in the `Custom` group, so only a console whose listing names it can,
and those consoles exist only on restored carriers. Admins spawn them from the Wolfgate tab's vessel spawner, where
the `WFOldVessel` tag puts them under Old vessels.

Each prototype is the pre-refactor file with only these changes: `group: Custom` (the old group is kept as a comment
and as `mapchecker_group_override`), `purchasable: false` (except the carrier craft, which keep their old value), the
`WFOldVessel` tag, the grid path, `BaseVesselAntag` renamed to `BaseVesselIFFDisabled`, and `guidebookPage: Null`
where the page no longer exists. The Kortik-EM uses the grid upstream kept
(`/SharedMaps/_Mono/Shuttles/PDV/kortik_em.yml`).

The grids are the pre-refactor files plus two changes. Every ship gun has a hardpoint of its class and size under
it, with the gun's rotation, since guns only fire from a hardpoint now. The carrier consoles of the Balor, Ledokol,
M-Class, Ravager, Tumour and Windreign are restored with a `WF` prefix (`carrier_consoles.yml`), because
`Resources/mono_migration.yml` deletes the old IDs on load. The Ledokol's rams are voucher only; spawn a
`ShipVoucherLedokolAttachment` to get them from its console.

To bring a ship back for good, move its prototype and grid to their own module, put back its real group, and drop
`purchasable: false` and the tag.
