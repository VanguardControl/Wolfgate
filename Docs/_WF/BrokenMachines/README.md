# BrokenMachines

Turns the industrial uranium processing centrifuge (`CentrifugeLathe`) and the automated laser drills (`LaserDrill`,
`StationLaserDrill`) into broken props. The replacements keep the upstream IDs, so the derelict drill site and saved
grids still load them, but they draw no power, have no UI and produce nothing. The Mono definitions are commented
out in place, and the laser drill flatpack is no longer sold on the MMC uplink or dropped as dungeon loot. The
flatpack itself still exists, builds the broken drill and sells for nothing.
