# SolarianGear

Solarian Alliance military kit ported from Lonestar by way of Panta-Rhei PR 1177 (Floof-Station/Panta-Rhei): the TSMC
M86 combat hardsuit and its helmet, the TSN M86 Mark Four hardsuit, Marine, Navy and Engineer jumpsuits, a Marine
backpack, a combat chest rig, a military headset, two berets and the Officer's and Admiralty cloaks. The sprites are
an orange recolour of Monolith's blue TSFMC M86 line. Nothing spawns them yet; they are for events and admin outfits,
and keep the port's entity IDs (`ClothingOuterHardsuitSolarianM86Hardsuit`, `ClothingUniformSolarianMarine`, ...).

The PR also recoloured the death squad hardsuit red and black; those sprites are the ones Wolfgate already ships, so
the Ashfall Reavers' red suit (`WFClothingOuterHardsuitReaver`) lives with their crew gear in the NpcCrew module and
reuses the upstream RSI.

Component differences from the port: `StaminaResistance` became `StaminaDamageResistance`, the helmet attaches through
Monolith's `clothingPrototypes` map, night vision uses Monolith's M86 helmet settings, `DamageOnShootProtection` and
the `HidesHarpyWings` tag (the hardsuit base already hides wings) were dropped, and the headset lost Floof's
`EncryptionKeyAdmeme2` key.
