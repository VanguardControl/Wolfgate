# GuidebookSearch

A search bar above the guidebook's contents tree. Typing hides the tree and lists the pages whose title or text
contain the search: titles that start with it first, then titles that contain it, then pages whose text has every word,
each with a line of text round the match. Click a result, or press Enter for the first, to open it. Clearing the
search brings the tree back.

It searches every page the window holds, including rule pages, which the tree leaves out except for the ruleset
itself. A page's text is read once, with markup and tags stripped; text that a tag writes in at runtime, such as
`<WGWildernessRule/>`, isn't searched.

`GuidebookWindow.Search.cs` is a partial of the stock window, hooked in by two marked lines in
`GuidebookWindow.xaml.cs` (build the bar, and search again when the window gets a new set of pages). The stock
per-page filter on chemistry pages is unchanged.
