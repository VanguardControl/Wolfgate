# BetterFire

Burning mobs and objects use TauCeti's fire sprites (TauCetiClassic PR #9238, by Udav Okruzhen) instead of the old
tgstation ones. A humanoid on up to 3 fire stacks shows `Generic_mob_burning` (TauCeti `generic_underlay`) over its
body. Above 3 stacks it shows `Standing` (`human_overlay`) over the body and `Standing_underlay` (`human_underlay`)
behind it. Other mobs with the generic state get the new generic fire; monkeys, mice and Resomi keep their own sprites.
Burning paper, blueprints and hats use `generic_overlay` as the `fire` state of `Effects/fire.rsi`.

Entry point: `FireVisualizerSystem.Underlay.cs` extends the upstream `FireVisualizerSystem`. When the fire RSI has a
state `X_underlay` next to a fire state `X`, it draws that state in a layer at the bottom of the sprite while `X` shows
on top. No prototype changes; the sprites replace the upstream RSI states in place.
